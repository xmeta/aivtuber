== Important migration completed in this checkpoint

The old #9 checkpoint used `ReflexRequest` as the LLM input. That is no longer allowed after #36.

This checkpoint changes the generative boundary to:

* `GenerationRequest.source_event: EventEnvelope` for routing, cancellation, audit, and provenance;
* `GenerationRequest.thinking: ThinkingRequest` for model input;
* `ThinkingEngine::generate(&ThinkingRequest)`;
* OpenAI-compatible wire input serializes only the bounded/versioned `ThinkingRequest` fields:
** schema version
** current curated input with trust/privacy labels
** typed performer/stream/recent context
** retrieval snapshot
** curated context
* no free-form `state`, `candidate_asset_ids`, raw event payload, or raw history is sent by the OpenAI adapter;
* `GenerativePipeline::run` validates both source event and ThinkingRequest and rejects provenance mismatch between them.

The main-side semantic embedding validation and #9 generated provenance validation were both preserved when resolving the AssetStore merge conflict.
