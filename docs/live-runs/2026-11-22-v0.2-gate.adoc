== After-action review

Expected:: A live performer that keeps a quiet stream alive without operator help.
Observed:: Before #87 S1 the performer was silent whenever chat was quiet. After S1, it spoke about once a minute in quiet windows, never over chat, and never failed. But 30% of initiative phrases repeated earlier phrases word for word, and the 10-minute budget left one 3-minute silence.
Why:: The anti-repetition input (the recent-initiative list) is advice to the model, not a check. The budget constants were set by design, not from a run.
Changes::
* #89 is now the constraint. It adds a text-free repeat counter, so repetition is measured rather than inferred, plus a deterministic exact- and near-duplicate check on generated phrases before commit.
* The budget defaults (#87) are revisited with the #89 measurements in v0.3. This is not changed now: a 60 s cadence with repeats is worse than a slower one without.
* #458 covers the OBS URL friction.
