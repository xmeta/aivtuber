# Japanese STT bench (EXP-0002, #92 S3a)

Throwaway measurement scripts behind
[`docs/experiments/EXP-0002-japanese-stt-bench.adoc`](../../../docs/experiments/EXP-0002-japanese-stt-bench.adoc).
They are not production code, are not imported by any crate or TypeScript package, and **CI does not run them**.
Read the record's limitations before using any number they produce.

Nothing large lives in the repository: no audio, models, binaries, virtual environments or per-clip results.
Everything is written under one work directory outside the repository, given by the environment variable `STT_BENCH_DIR`.
The scripts contain no machine paths.

## Layout of `$STT_BENCH_DIR`

```
dl/     downloaded third-party material (untrusted data; created by fetch_assets.py, every file sha256-checked)
eval/   wav/ (trimmed 16 kHz clips) and eval.json (id, wav, gold text, duration)     (generated by build_eval.py)
out/    one JSON per run (per-clip text and timings, partials, load time, RSS)        (generated by bench.py)
```

Keep the work directory away from the scripts directory and run Python with `-I` (isolated mode: no current-directory or
`PYTHON*` path lookups) and `-X utf8`. The scripts add their own directory to `sys.path` explicitly.
Disk: about 12 GB for `dl/` (the Whisper float models and Vosk big model dominate), 0.2 GB for `eval/`.

## Reproduction

Python 3.13, CPU only, Windows x64 (the whisper.cpp binary pinned in `fetch_assets.py` is the Windows build; on another OS
use that platform's asset and adjust `WhisperServer` in `engines.py`).

```sh
python -m venv venv && venv/bin/pip install -r requirements.txt          # Windows: venv\Scripts\...
export STT_BENCH_DIR=/path/outside/the/repo/stt-bench                    # PowerShell: $env:STT_BENCH_DIR = "..."
PY="python -I -X utf8"

$PY fetch_assets.py [--with-gpu]     # pinned downloads, sha256-verified, extracts archives (about 7 GB; the GPU build adds 0.7 GB;
                                     # GitHub release URLs sometimes answer HTTP 504: `gh release download` fetches the same file)
$PY build_eval.py 400                # seeded 400-clip Common Voice ja sample -> eval/ (seed 20261109)
$PY bench.py --engine sherpa:k2v2-int8 --threads 4          # one engine, fresh process (see engines.py for engine names)
$PY run_all.py [--gpu]               # the whole matrix of the record, sequentially (about 3 hours on CPU)
$PY summarize.py [--first 200] [--drop-common-bad] [tag-substring ...] > "$STT_BENCH_DIR/out/summary.txt"
                                     # plain-text tables; STT_BASE=<tag> adds paired CER differences against that run
$PY preroll_sensitivity.py           # CER of one engine as the segment start moves relative to the speech onset
$PY streampad_probe.py               # CER of a streaming engine against the length of trailing zeros before input_finished()
```

`run_all.py` runs the Whisper models on the first 150 clips and the Vosk big model on the first 60 only, because they are
slow on CPU; compare engines on the same clips (`summarize.py --first N`).

Engine names: `sherpa:k2v2-int8`, `sherpa:k2v2-fp32`, `sherpa:k2-ja-en`, `sherpa:parakeet-ja`, `sherpa:sensevoice`,
`sherpa:dolphin-small`, `sherpa:omnilingual-300m`, `sherpa:qwen3-asr`, `sherpastream:nemotron-560[@pad1.0]` and
`sherpastream:nemotron-160[@pad1.0]` (native streaming, `@padN` appends N seconds of zeros before `input_finished()`),
`vosk:small`, `vosk:big`, `whisper:<ggml model name without the "ggml-" prefix and ".bin">`, and
`whispergpu:<same>` for the CUDA build (needs `fetch_assets.py --with-gpu`).

Timings are wall-clock on one machine and vary with CPU and background load; run on a quiet machine, never two runs at once.
`bench.py` reports, per run: CER inputs, per-call latency of the final transcription, real-time factor, first-call time, load time,
peak working set, emulated partials, and a same-process re-run to check that the same input gives the same text.
`summarize.py` also compares runs of the same engine (threads, processes).

## Normalisation (applied identically to gold and hypothesis)

NFKC, lower-case, then every Unicode category P*, S*, Z*, C* character is removed. Nothing else is rewritten.
The secondary "number-insensitive" view collapses every run of digits and kanji numerals into one `#`.
CER is micro-averaged (sum of Levenshtein distances over sum of reference characters); the interval is a 2000-sample
bootstrap over clips (seed 20261109).
