= Starter Cached Reaction Pack

This pack is a source-controlled descriptor/timing fixture for the Rust cached playback path.

It contains four families with two variants each:

* `reaction.surprise`
* `reaction.agree`
* `filler.thinking`
* `reaction.neutral` (speechless: an expression and a nod, no audio and no viseme track; the `local` profile and any route without a fallback group play it when generation fails, issue #288; it uses only presets the local avatar renderer draws, and has no semantic embedding so it is never a retrieval candidate)

`descriptors/` contains Performance Asset JSON files. Each starter descriptor also carries a small precomputed `starter-semantic@1` embedding used by AssetStore -> `SemanticIndex` integration tests; production retrieval never computes these embeddings in the scheduler/frame path. `viseme/` contains compact local timing tracks consumed by `crates/runtime::cached_playback`.

Audio remains external through `audio://starter/...` references. Generated audio binaries are intentionally not committed to Git.

== Starter audio (generated locally)

Six descriptors name `audio://starter/*.opus` (`reaction.neutral` is speechless). Generate the files on your machine with the pinned local TTS sidecar (Supertonic 3 int8, language `ja`, text-derived seed, speaker 0):

[source,sh]
----
node scripts/synthesize-starter-audio.mjs --sidecar target/release/local-tts-sidecar --model-dir /path/to/supertonic-model-dir
----

The files and a `PROVENANCE.json` (model alias and bundle digest, seed rule, SHA-256 of each file, OpenRAIL-M notice) land in `audio/starter/` beside this README, which is the app's default audio root and is git-ignored. The step needs ffmpeg with libopus and does not change the descriptors' `voice_model` (`example-voice-v1`, the default `AIVTUBER_VOICE_MODEL`). See `docs/local-profile-quickstart.adoc` ("Starter reaction audio").

Decision (#289): generated locally rather than shipped, because the weights are OpenRAIL-M, this project does not redistribute them or generated media, and the voice stays the one the operator's own sidecar produces. Without the files, or if `AIVTUBER_VOICE_MODEL` differs, `aivtuber-app` prints one counted `pack_readiness: WARNING` at start naming the unusable descriptors and the reasons.

The fast-path preload policy loads compatible `filler` and `reaction` descriptors into the L0 asset cache. Variant selection is deterministic for a recorded seed and excludes the immediately recent variant when another compatible variant exists.
