= Starter Cached Reaction Pack

This pack is a source-controlled descriptor/timing fixture for the Rust cached playback path.

It contains four families with two variants each:

* `reaction.surprise`
* `reaction.agree`
* `filler.thinking`
* `reaction.neutral` (speechless: an expression and a nod, no audio and no viseme track; the `local` profile and any route without a fallback group play it when generation fails, issue #288; it uses only presets the local avatar renderer draws, and has no semantic embedding so it is never a retrieval candidate)

`descriptors/` contains Performance Asset JSON files. Each starter descriptor also carries a small precomputed `starter-semantic@1` embedding used by AssetStore -> `SemanticIndex` integration tests; production retrieval never computes these embeddings in the scheduler/frame path. `viseme/` contains compact local timing tracks consumed by `crates/runtime::cached_playback`.

Audio remains external through `audio://starter/...` references. Generated audio binaries are intentionally not committed to Git.

The fast-path preload policy loads compatible `filler` and `reaction` descriptors into the L0 asset cache. Variant selection is deterministic for a recorded seed and excludes the immediately recent variant when another compatible variant exists.
